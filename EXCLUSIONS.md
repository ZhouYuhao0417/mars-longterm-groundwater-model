# Excluded artifacts and claims

The file `data/excluded/medium_summary_incomplete.json` is an older interrupted medium attempt retained only for auditability, with `complete=false`, `paper_usable=false` and `completed_years=3.72798923954534`. It must not be confused with the later accepted `medium_f64_v2` run exposed in `data/accepted-v2/`.

The following are intentionally not distributed as publication results:

- depth, arrival or duration rasters from the interrupted old medium checkpoint;
- any map derived from that incomplete checkpoint;
- outputs from the withdrawn semi-distributed storage-routing/HAND model;
- any claim that the northeast–southwest Nili Fossae trough supplies surface water to the equivalent source or hydraulically reaches Jezero's western-delta headwaters;
- screen-pixel measurements from the interactive preview.

The accepted `medium_f64_v2` record is a separate 20-year result: 2.660227 years of analytical source-basin prefill plus 17.339773 years of explicit float64 routing at 600 s with no skipped downstream time. The old high run remains legacy exploratory only and is not presented beside the accepted v2 low/medium pair as a same-version manuscript result.
